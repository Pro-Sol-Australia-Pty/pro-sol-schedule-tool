Import template

Use Export Excel to download the current schedule structure. The workbook now uses MS Project-compatible headers such as ID, Task Name, Start, Finish, Predecessors and Resource Names. Required import columns are ID or Unique ID, Task Name, Start, and either Finish or Duration. Category remains optional for MS Project imports and defaults to MS Project Import when absent. Optional lower levels can be created with Parent ID and Outline Level. Schedule logic can be entered in MS Project-style Predecessors values such as 3FS+5d, or by using the separate Relationship helper column.

Accepted formats

  • .xlsx / .xls import and export use the same schedule workbook structure. Export the current schedule, edit it in Excel, then import it back for bulk updates.
  • .csv import and export works as a fallback without the Excel library.
  • Date fields should use yyyy-mm-dd. Excel date cells are converted automatically during import.
  • Relationship defaults to FS finish-to-start when a predecessor is entered and the relationship cell is left blank. When saved, successors that start before their required predecessor logic date are pushed forward automatically. Milestone activities default to the controlling predecessor finish date, with both start and finish set to that same date. Project Milestones is included as a default WBS category in the Interactive Gantt; milestone-tagged activities are mirrored there for reporting visibility without changing the editable table.
  • Use Parent ID to nest an activity under another activity. Category rows are generated automatically as Level 1 WBS summary rows.
  • Use the Milestone column to mark an activity as a milestone. Milestones display as diamonds in the Interactive Gantt and are also shown under the default Project Milestones WBS category in the Gantt view only.
  • Use the Columns menu in the Table / Import tab to hide or show optional fields. MS Project compatibility fields are included there but hidden by default.

Save behaviour

Click Save Table Changes after editing the table. The Gantt redraws from the table data, updates dependency arrows from the predecessor and relationship columns, and stores the latest version in the browser. Use Save Tool to export a self-contained HTML copy with the current schedule embedded. Use Generate Interactive Viewer to export a read-only HTML copy that keeps the schedule browsable while disabling editing, imports, exports and save controls. Viewer tabs, filters, zoom and expand/collapse controls stay functional. Use the Dashboard tab for the recommended executive schedule visuals: KPI cards, progress health, category workload, milestone timeline, critical path watchlist and upcoming 90-day activities. Use Export to download Excel, PDF, or PowerPoint outputs from the current schedule. PDF and PowerPoint exports include a landscape snapshot of the current Interactive Gantt view.

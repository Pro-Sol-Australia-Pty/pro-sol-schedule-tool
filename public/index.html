Import template

Use Export Excel to download the current schedule structure. Update the workbook in Excel, then import it back into this tool for bulk data updates. Required columns are Activity ID, Category, Activity Name, Start Date and Finish Date. The table and Gantt both use Category as Level 1 and indent activities as Level 2 by default. Use the row arrows or the Expand All / Collapse All buttons to open or close WBS levels. Use Sort WBS to reorder Level 1 categories across the Table, Dashboard and Interactive Gantt. Table and Interactive Gantt collapse states are kept separate. Optional lower levels can be created with Parent ID and WBS Level. Schedule logic is entered using two separate columns: Predecessor for Activity IDs and Relationship for the link type, for example FS or FS+5d.

Accepted formats

  • .xlsx / .xls import and export use the same schedule workbook structure. Export the current schedule, edit it in Excel, then import it back for bulk updates.
  • .csv import and export works as a fallback without the Excel library.
  • Date fields should use yyyy-mm-dd. Excel date cells are converted automatically during import.
  • Relationship defaults to FS finish-to-start when a predecessor is entered and the relationship cell is left blank. When saved, successors that start before their required predecessor logic date are pushed forward automatically. Milestone activities default to the controlling predecessor finish date, with both start and finish set to that same date. Project Milestones is included as a default WBS category in the Interactive Gantt; milestone-tagged activities are mirrored there for reporting visibility without changing the editable table.
  • Use Parent ID to nest an activity under another activity. Category rows are generated automatically as Level 1 WBS summary rows.
  • Use the Milestone column to mark an activity as a milestone. Milestones display as diamonds in the Interactive Gantt and are also shown under the default Project Milestones WBS category in the Gantt view only.
  • Use the Columns menu in the Table / Import tab to hide or show optional fields. The default view uses the same columns as the Interactive Gantt.

Save behaviour

Click Save Table Changes after editing the table. The Gantt redraws from the table data, updates dependency arrows from the predecessor and relationship columns, and stores the latest version in the browser. Use Save Tool to export a self-contained HTML copy with the current schedule embedded. Use the Dashboard tab for the recommended executive schedule visuals: KPI cards, progress health, category workload, milestone timeline, critical path watchlist and upcoming 90-day activities. Use Export to download Excel, PDF, or PowerPoint outputs from the current schedule. PDF and PowerPoint exports include a landscape snapshot of the current Interactive Gantt view.
